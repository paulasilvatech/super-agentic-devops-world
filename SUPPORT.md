# Support

Thanks for using **Super Agentic DevOps World**! 🎮 Here is how to get help.

## 📖 Start with the content

Most questions are answered directly in the guide:

- **New to everything?** Begin at
  [World 1‑1 — VS Code](en/world-1-green-plains/1-1-vs-code.md) and follow the
  worlds in order.
- **Looking for a specific topic?** Check the
  [README topic map](README.md#-topics-covered) or the
  [glossary in World 8](en/world-8-final-castle/).
- Reading in Portuguese? Start at [`pt-br/README.md`](pt-br/README.md).

## 💬 Ask a question

- **GitHub Discussions** (preferred for open‑ended questions, ideas, and "how do
  I…?"): <https://github.com/paulasilvatech/super-agentic-devops-world/discussions>
- **Issues** (for concrete problems): use the
  [issue templates](https://github.com/paulasilvatech/super-agentic-devops-world/issues/new/choose)
  when something is wrong — a typo, a broken link, an incorrect explanation, a
  translation mismatch, or a website bug.

## 🐛 Reporting problems

| I want to… | Where to go |
|:--|:--|
| Report a content error, typo, or broken link | [New content issue](https://github.com/paulasilvatech/super-agentic-devops-world/issues/new/choose) |
| Report an EN ↔ PT‑BR mismatch | [New translation issue](https://github.com/paulasilvatech/super-agentic-devops-world/issues/new/choose) |
| Report a website bug | [New bug report](https://github.com/paulasilvatech/super-agentic-devops-world/issues/new/choose) |
| Suggest a new level or topic | [New idea](https://github.com/paulasilvatech/super-agentic-devops-world/issues/new/choose) |
| Report a security vulnerability | [SECURITY.md](SECURITY.md) (do **not** open a public issue) |

## 🤝 Want to contribute?

See [CONTRIBUTING.md](CONTRIBUTING.md) for how to fix content, translate, or work
on the website.

> [!NOTE]
> This is a community‑maintained educational project. Support is provided on a
> best‑effort basis by volunteers — please be patient and kind. 🍄
